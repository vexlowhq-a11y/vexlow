Agregar diapositiva

Acá se publican las noticias completas: al guardar con "Cuerpo" cargado, se genera directamente la página del artículo dentro de categoria/{categoría}/{slug}.html, con carrusel, sidebar y "Últimas noticias" ya enlazados. No hace falta pedírselo a nadie.

Agregar artículo

Busca titulares recientes en feeds RSS de noticias (configurados en admin/feeds.json) y redacta un artículo original para cada uno con IA — nunca copia el texto de la fuente. Quedan acá como borrador: revisalos, editalos si hace falta, y usá "Usar este borrador" para pasarlos al formulario de "Últimas publicadas" y publicarlos.

El bot busca noticias nuevas, escribe el artículo, elige la categoría y el tema (creándolo si hace falta), lo publica y lo sube a vexlowhq.com solo — sin que revises nada a mano. Corre en tu PC cada 6 horas mientras esté prendida (tarea programada de Windows). Las imágenes las seguís poniendo vos: un artículo entra al carrusel principal recién cuando ya tiene una imagen puesta.

Si la apagás, las noticias vuelven a quedar en "Borradores sugeridos" para revisarlas vos como antes — no se pierde nada.

Historial de corridas

Estas son las categorías principales del menú del sitio (sidebar, footer y chips de filtro). Agregar una acá no le pone su propia sección en la portada -- eso queda para cuando ya tenga artículos, así no se repite el problema de categorías vacías. Después de agregar, renombrar o eliminar, hay que publicar los cambios para que se vean en el sitio.

Agregar categoría

El slug (la URL) sale del nombre y no se puede cambiar después -- para eso hay que eliminar y crear de nuevo.

Elegí un nivel, tocá la pista para agregar el obstáculo seleccionado en la paleta, arrastrá lo que ya está puesto para moverlo (o usá "✋ Mover" para arrastrar sin riesgo de agregar uno de más). Al elegir una herramienta aparece abajo su molde/sprite, con un "+" para subir uno propio ahí mismo. "Verificar con bot" corre el mismo bot que se usó para probar que cada nivel sea pasable — hacelo antes de guardar.

Abre el nivel guardado de verdad en una pestaña nueva, arrancando justo en ese punto (probá guardar primero para que sea lo último que armaste).

Clic en la pista: agrega el obstáculo elegido arriba. Clic sobre uno ya puesto: lo selecciona (arrastralo para moverlo). Con uno seleccionado aparece un punto verde en su esquina — arrastralo para cambiarle el tamaño. Ctrl+C / Ctrl+V: copia y pega el seleccionado. Supr / Backspace: borra el seleccionado. Lo que ves acá es el tamaño real del juego (a escala según el zoom elegido), no un boceto.

Objetos del nivel

Si algo quedó gigante, mal puesto o no lo podés tocar en la pista, borralo o seleccionalo desde acá.

Techo / paredes del nivel

Fondo del nivel

Podés subir una imagen fija o un GIF animado (se mueve solo, a media velocidad del juego). Si es una imagen muy cargada, oscurecela un poco para que el piso y el techo se sigan viendo claros.

Zonas de velocidad

Crea un nivel nuevo (empieza vacío, solo con la meta puesta) y lo agrega a la lista — después lo armás en "Editar niveles". Se le genera una miniatura simple automáticamente; podés reemplazarla luego desde "Sprites".

Acá están los sprites que no son un molde de obstáculo (esos se suben desde la paleta en "Editar niveles", al lado de cada herramienta): las imágenes base del juego, la decoración del menú, las miniaturas de nivel y las skins. Se sube tal cual, sin recortar: si tiene fondo transparente (PNG) mejor.
